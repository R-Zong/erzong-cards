# 场景排法

每个场景写清：一组怎么排、图从哪来、常见的坑。一组建议 ≤ 9 张（小红书最多 18 张，公众号图片消息最多 9 张）。

## 信息向

| 场景 | 典型的人 | 一组的顺序 | 图从哪来 | 常见的坑 |
|---|---|---|---|---|
| 产品介绍 | 新媒体运营、品牌 | C01 → G02 → N01 → X03 / X01 | 用户的产品图（白底、浅灰底、透明图） | 卖点写成长句；参数没核实 |
| 观点笔记 | 职场人、博主 | C02 → T01 → T03 → T05 | 一般不用图 | 一页塞多个观点 |
| 教程拆解 | 老师、教程博主 | C02 → X05 → X02 → T04 | 截图、步骤图 | 步骤超过 5 步不拆页 |
| 课程笔记 / 考试重点 | 学生 | C02 → T03 → X02 → T04 | 一般不用图 | 抄书式大段文字 |
| 数据复盘 | 职场人（述职、年终总结） | C02 → N02 → N03 / N04 → T01 | 不用图 | 一页数字太多 |
| 截图解读 | 资讯、AI 博主 | C03 → T01 / T03 / X04 | 用户的截图 | 第一张就塞解读；长截图没先问 |
| 长文原样做成图 | 公众号作者 | C02 → T02（自动分页） | 原文配图 | 被压缩成卡片后读不完整 |

## 生活向（要用户给照片）

| 场景 | 一组的顺序 | 常见的坑 |
|---|---|---|
| 旅行攻略 | I01（full 或 bleed）→ I03（天数、花费、步数）→ X05 路线 → I02 / I04 | 写成"必去十大景点"的空话；每页留一个具体细节（日期、天气、里程） |
| 探店 | I01 → I03（人均、排队、出片位）→ I02 → T03 | 只有图没有信息 |
| 美妆教程 / 种草 | C01 或 I01 → X05 → X03 → T03 | 色号凭照片取色会不准，要用品牌官方色号 |
| 穿搭分享 | I01 → I02（一周穿搭）→ T03 | 全身照裁到头脚 |
| 好物种草 | C01 → G02 → N05 / X03 → T03 | 价格没写时间 |
| 花费账单 | C02 → N05 → T03 | 金额没核对 |

## 一页一件事

- 一页 = 1 个标题 + 1 个主体（截图 / 一组列表 / 一组数字 / 一张图），外加最多 1 个辅助（眉题、副标题、注释三选一）。
- 同一页不放两组不同的列表；列表一组最多 4～5 项。
- 别人的原话（截图）和自己的观点分开放：先给原话，再讲看法。
- 补充说明、注意事项放不下时，建议写进笔记正文，不硬塞进卡片。
- 不设专门的结尾页；用户写了总结就按普通内容排，没写不替他加。
