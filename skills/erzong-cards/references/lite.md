# 简易档（平台不能运行脚本时）

完整档用 `engine/render.cjs` 出图，会做图片处理和质检。有的平台只能写文件、不能运行命令，这时用简易档：

1. 复制 `lite/template.html`，放在同一个 `lite/` 文件夹里（例如 `lite/我的笔记.html`），因为它用相对路径找字体和样式。
2. 只改文件里的 `window.DECK = {...}`，格式和完整档的内容文件一样（见 `deck-format.md`）。图片路径相对于这个 HTML 文件。
3. 让用户用浏览器打开（平台自带的网页预览也可以），排好后点上面的"下载全部图片"。

简易档的限制（要告诉用户）：
- 不做产品图换底、渐隐这类图片处理，照片和截图照常显示。
- 质检结果显示在卡片上的红条里，不会自动修。
- 直接双击打开 HTML 时，有的浏览器不让网页读本地字体，下载会失败；这时用平台的网页预览打开，或者装好完整档出图。
